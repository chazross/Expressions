# Expressions Project  
**Created by:** Chaz Ross  
🔗 [View on GitHub](https://github.com/chazross/expressions)

## Project Overview:
<p>Expressions is a creative front-end web application that brings together art, quotes, and humor in a sleek, responsive interface. The goal was to build an engaging and easily navigable platform where users can search and share expressive content like GIFs, images, and quotes—perfect for social media, messaging, or email.

Designed with simplicity and usability in mind, this project showcases my ability to build visually appealing, interactive UIs with responsive design principles.</p>

### Key Features
- Responsive navigation bar with dropdown menus, optimized for mobile and desktop
- User-friendly interface with clean layout and intuitive flow
- GIF search functionality powered by keyword input
- Designed for quick sharing across social platforms, email, and SMS

### Technologies:
- HTML5 – semantic structure and accessible layout
- CSS3 – styling and layout foundation
- JS (ES6)  – interactivity and dynamic content

 - Implement pagination for GIF search results
